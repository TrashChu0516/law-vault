# Error Ledger — template

One row per error caught in a marked attempt or drill. Terse. "Fix drill" = what to run next session.

**Rule:** the same error twice becomes the next session's drill, drilled to death.

| Date | Drill | Topic | Error | Correct move | Fix drill | Status |
| --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  | open |
|  |  |  |  |  |  | open |

## Status values

- `open` — not yet re-drilled.
- `drilled` — re-drilled once; watch for recurrence.
- `closed` — clean under time, twice.

## How to write a row

- **Error** — what went wrong, in the marker's language, not a vague label. "Missed the inquiry-vs-counter-offer fork" beats "offer issue weak".
- **Correct move** — the rule or step that should have been applied, with authority.
- **Fix drill** — the specific drill and the time box. "Bank T19; redo Q1 in 8 min", not "revise formation".
