# `Grill/`

The exam-performance layer. Notes are input; this folder is where they become marks.

| Folder | Module | What it holds |
|---|---|---|
| [`CL1_Contract/`](CL1_Contract/) | Contract Law | IRAC rubric, professor's exam technique, trigger banks, error ledger, `attempts/` |
| [`CRL_Criminal/`](CRL_Criminal/) | Criminal Law | CRL marking rubric, checklists, mastery ledger, drill sheets, error ledger, `attempts/` |
| [`_shared/`](_shared/) | — | `The ELEMENTS of STYLE.md` — the writing standard both modules mark against |

**Separation rule:** a CL1 artefact never goes in `CRL_Criminal/`, and a CRL artefact never goes in `CL1_Contract/`. Only genuinely cross-module standards live in `_shared/`.

In the private vault this folder also holds the filled ledgers and marked attempts. Those are working documents, not published.
