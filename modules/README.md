# `modules/`

Module-level material that is not a case and not a personal note.

```
modules/
├── CL1_Contract/Statutes/     ← verified statute banks (SSO)
├── CRL_Criminal/Interpretations/
├── LRW/
└── SLS/Statutes/
```

A statute bank is a transcription of the provisions that matter for the module, with the SSO URL and retrieval date in the frontmatter, and the section numbers preserved so an exam answer can cite `s 3(1)` and link to the note.

A sample is included at [`CL1_Contract/Statutes/Unfair Contract Terms Act 1977.md`](CL1_Contract/Statutes/Unfair%20Contract%20Terms%20Act%201977.md). The other four banks are private.
