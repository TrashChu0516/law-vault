# `Textbook/`

Two things live here in the private vault:

1. **The textbook PDFs** — the spine for each module. Publisher copyright; never committed to git.
2. **The generated exam summaries** — one per week, built by the `exam-summary-pipeline` skill from the chapter, the seminar outline, the case notes and the statute bank.

The summaries are the highest-value output of the system: a mini-textbook per chapter, with rule statements, a case ledger, I/R/A pre-writes and typing-drill packs. The Week 7 contract summary is the exemplar the other weeks are built against.

This folder is git-ignored in the private repo — the PDFs because of copyright, the summaries because they quote the textbook closely. This showcase carries the pipeline that produces them, not the products.
