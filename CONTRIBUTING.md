# Contributing

This is primarily a personal study system published as a showcase. Small fixes — typos, broken links, stale paths — are welcome.

## Before you open a pull request

- Run `python3 _tools/check_paths.py` if you changed a path referenced in `AGENTS.md` or a skill spec.
- Do not add copyrighted PDFs, seminar outlines, past papers, marked attempts or personal data.
- Keep the module separation: `Grill/CL1_Contract/` is contract only; `Grill/CRL_Criminal/` is criminal only.

## Sign-off (DCO)

By contributing, you certify the [Developer Certificate of Origin 1.1](https://developercertificate.org/) and agree to license your contribution under the repository's terms for the part you touched: MIT for code, reserved for written content unless agreed otherwise.

Add a sign-off line to each commit:

```
Signed-off-by: Your Name <you@example.com>
```

`git commit -s` adds it automatically.
