# `cases/`

One note per case. In the private vault this folder holds **237 Markdown notes** and 23 judgment PDFs across four modules, grouped by teaching week:

```
cases/
├── CASE_INDEX.md          ← Dataview index over every case
├── CL1_Contract/
│   ├── CL1_MOC.md
│   ├── wk_1/ … wk_10/
├── CRL_Criminal/
├── LRW1/
└── SLS/
```

Each note follows `_templates/t-case-note.md`: YAML frontmatter (citation, court, coram, date, topic, tags), then an exam-ready paragraph, the ratio bank, the brief, the deep dive and — at the bottom, unmodified — the judgment text.

A sample is included at [`CL1_Contract/wk_7/Speedo Motoring Pte Ltd v Ong Gek Sing [2014] SGHC 71.md`](CL1_Contract/wk_7/Speedo%20Motoring%20Pte%20Ltd%20v%20Ong%20Gek%20Sing%20%5B2014%5D%20SGHC%2071.md).

The rest of the library is private: volume, and editorial headnotes that may carry publisher rights.
